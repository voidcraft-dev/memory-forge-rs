# HUD 界面设计稿

这两个文件是 memory-forge 的静态 UI 设计稿，用浏览器直接打开即可预览，不参与构建，也没有接入 Tauri 后端。

- `memory-forge-hud.html`：v1，左侧图标导航 + 概览仪表盘 + 三栏会话布局
- `memory-forge-hud-v2.html`：v2，顶部视图切换（概览 / 工作台 / 记忆库 / 图谱 / 关于），以会话时间轴为导航、消息流为工作台，右侧检查器抽屉，带 `Ctrl+K` 命令面板

说明：

- 所有数据均为内置演示数据，会话、记忆、审计记录都存在 `localStorage`，与真实适配器无关。
- 「记忆库」「图谱」「记忆萃取」是设计概念，当前应用尚未实现；记忆条目内容也是虚构的。
- 底部 HUD 调校坞用于预览配色、字体、粒子等主题参数，不是正式功能入口。

保留这两份文件是为了后续 UI 重构时对照讨论，暂不落地。
