MEMORY FORGE · 记忆锻造

v2.0-workbench · 单文件交互原型

为 memory-forge-rs 设计的第二代 HUD。相对 v1 的三栏布局，v2 把「时间」作为第一导航维度：三条代理泳道的会话时间轴取代会话列表；消息流获得全宽聚焦阅读区；检查器收进右侧抽屉，把空间还给主任务；Ctrl+K 命令面板统一跳转会话 / 记忆 / 视图 / 操作。

保留 v1 全部能力：消息级编辑删除（可撤销）、重命名、复刻、导出、记忆萃取与锻造、力导向图谱、常驻调校坞。数据存于 localStorage（独立于 v1），可随时恢复。
